# Separate frontal squat tracking from side-view squat analysis

Frontal squat videos use a dedicated tracking-and-rep-counting analysis mode instead of reusing side-view depth and torso judgments. Automatic bilateral pose tracking remains the default, optional partial body anchors may assist any of the eight lifter-side shoulders, hips, knees, and ankles, and knee/ankle trails expose only the preceding second of motion. Barbell output is omitted unless three-quarter footage provides a reliably tracked visible collar; inferred bar-center paths are not emitted.
