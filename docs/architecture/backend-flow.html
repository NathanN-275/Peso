Analysis pipeline

What happens inside one run

Each stage preserves diagnostics so limited or uncertain results can be explained instead of silently overstated.

01 · Load

Read video metadata

Find the owned row and start a development trace when tracing is allowed.

→
02 · Download

Fetch private source

Validate the user storage path and download to a temporary file.

→
03 · Estimate

Pose estimation

Sample frames with MediaPipe and use RTMPose fallback for difficult clips when enabled.

→
04 · Assist

Fuse tracking anchors

Use valid user pins without forcing uncertain tracks to look confident.

↓
05 · Stabilize

Detector prepass + pose repair

Reject identity switches, repair short gaps, and retain longer uncertain gaps.

→
06 · Interpret

Exercise analysis

Segment reps, calculate depth, torso and velocity signals, and build Lift Insights.

→
07 · Track

Build barbell path

Preserve the visible collar identity and expose coverage and failure diagnostics.

→
08 · Persist

Save result + assets

Store structured analysis, thumbnail, optimized playback, timing, and completion state.
