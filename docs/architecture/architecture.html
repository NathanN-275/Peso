Important boundaries

What stays separate

The boundaries are part of the design, not duplicate implementations.

Marketing vs product

Static pages do not load account state

Astro owns public routes. The signed-in React Router app lives under /app.

Facts vs observations

Performed Reps stay user-owned

Detected Reps are a model observation. Performed Reps and Load are workout facts.

Demo vs server work

Demo Analysis stays on-device

It creates no upload, backend request, quota charge, or durable record.

Public vs internal

The dashboard is not an athlete surface

Development diagnostics remain local and are unavailable when production tracing is disabled.
