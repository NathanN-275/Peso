Athlete flow · Mobile

Capture. Analyze. Review. Save.

The Expo mobile app is the direct phone workflow. It uses the same Peso Account, backend, and Saved Lift Library as the planned Web Beta.

Primary journey

A lift becomes a Saved Lift

01 · Account

Welcome → sign in or create account

Supabase Auth creates or restores the Peso Account session.

↓
02 · Home

Review progress or add a video

Home shows Saved Lift summaries. The add action opens record and upload choices.

↓
03A · Capture

Record a set

Use the phone camera, review the clip, and continue with the recording.

03B · Select

Upload an existing video

Choose a compatible workout video already saved on the device.

↓
04 · Setup

Confirm exercise, view, and tracking help

For supported clips, the athlete can place body and barbell anchors on a reference frame.

↓
05 · In progress

Side-squat recording guide + quality preflight

Framing guidance and server quality checks catch unusable side-view squat clips before full analysis.

↓
06 · Process

Upload → register → analyze → poll

The client uploads to private Supabase Storage, registers the owned video, starts backend analysis, and polls status.

↓
07 · Review

Inspect playback, tracking, insights, and coaching

The result separates model observations from user-owned workout details.

Review decision

Keep it or remove it

Does the athlete want this result in their history?

↓
Save

Add workout details

Performed Reps, Load, and notes are optional user-owned facts. Saving moves the result into the shared Saved Lift Library.

Discard

Remove the unsaved analysis

The backend deletes eligible video and analysis data instead of keeping a hidden result.

Return journey

Saved Lifts are shared

A saved analysis is not a mobile-only copy. The same library is available through the Web App.

Browse

Home or lift folder

Open recent lifts or browse by exercise.

→
Open

Refresh playback URL

The backend checks ownership before signing private media.

→
Review

Replay the saved analysis

Tracking overlays, rep insights, coaching, and workout facts return together.

→
Optional

Delete permanently

Deletion removes the same Saved Lift from mobile and web.
