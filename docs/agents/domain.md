# Domain Docs

Peso is a single-context repository. Before exploring a feature, read the root `CONTEXT.md` and relevant `docs/adr/` decisions when they exist. If they do not yet exist, proceed without flagging their absence.

When a domain-modeling workflow establishes stable terminology or a durable architectural decision, create or update the relevant context or ADR document. Use its established vocabulary in issue titles, test names, and implementation notes.
